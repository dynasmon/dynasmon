## About me

I'm a security practitioner focused on **offensive security, penetration testing, and adversary-informed engineering**. I assess web applications, internal networks, Linux hosts, cloud infrastructure, and segmented Windows environments.

- **Security assessments:** web applications, networks, Linux, Windows, and cloud environments
- **Adversarial research:** attack-path analysis, privilege escalation, lateral movement, and segmentation testing
- **Security engineering:** endpoint telemetry, detection pipelines, event correlation, and automation

---

## Seagull

[Seagull](https://github.com/dynasmon/Seagull) is an open-source SIEM and security operations platform for collecting, correlating, and investigating endpoint and network telemetry.

### Try to Hack me

A public Seagull instance is available for security research. You are welcome to assess it and report security findings responsibly.

<p align="center">
  <a href="https://seagull.dyn4sm0n.cloud/"><strong>seagull.dyn4sm0n.cloud →</strong></a><br>
  <sub>Public Seagull instance for public security testing</sub>
</p>

> [!IMPORTANT]
> Testing authorization applies only to infrastructure and assets that I own or explicitly control. Do not target third-party services or perform denial-of-service, destructive testing or actions that could disrupt other users.
