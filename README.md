## About me

I work primarily with **penetration testing and offensive security**, assessing web applications, networks, Linux environments, cloud infrastructure, and segmented Windows LAN environments.

My work includes internal network assessments focused on attack surface discovery, segmentation boundaries, privilege escalation paths, lateral movement opportunities, and the security posture of Windows-based corporate networks.

My broader research is centered around identifying attack surfaces, understanding how vulnerabilities can be chained into meaningful attack paths, and evaluating systems from an adversarial perspective.

Alongside offensive security, I develop security tooling and infrastructure to better understand detection, telemetry and defensive controls from the other side of the attack lifecycle.

### Security Operations Platform

**Seagull** is an open-source SIEM and security operations platform that I am actively developing.

It collects endpoint and network telemetry and transforms it into actionable security context through **detection rules, event correlation, attack-chain analysis, vulnerability intelligence and behavioral analytics**.

The platform includes an independent **Go endpoint agent**, a **FastAPI control plane**, distributed processing workers and a **React-based analyst interface**.
